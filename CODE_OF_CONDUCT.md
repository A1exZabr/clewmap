# Code of conduct

Clewmap follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, keep criticism about the code, and do not harass anyone in
issues, pull requests, discussions or anywhere else the project is represented.

To report a problem, use GitHub's private reporting: open the repository's Security tab and choose
"Report a vulnerability", or contact the maintainer through their GitHub profile. Reports are kept
confidential. The maintainer may remove comments, close threads or block accounts that break these rules.
