# Clewmap — контекст для Claude Code

Open source (MIT) инструмент: живая карта кода в репозитории, объяснения функций прямо в редакторе, обновление графа на каждом коммите, MCP для агентов.

## Документы
- `docs/clewmap-vision.md` — что строим и зачем
- `docs/clewmap-ai-plan.md` — пошаговый план по фазам 0–5, выполнять строго по порядку
- `docs/mockups/editor.html`, `docs/mockups/flow.html` — макеты UI и схемы, UI расширения должен им соответствовать

## Как работать
- Выполняй одну фазу за раз. В конце фазы прогони её «Проверку» и покажи результат, потом жди подтверждения перед следующей.
- Отмечай выполненные пункты `- [x]` в `docs/clewmap-ai-plan.md`.
- Если пункт плана расходится с реальностью (API библиотеки изменился, имя занято), не придумывай: предложи вариант и спроси.

## Жёсткие правила
- Связи между символами строит только tree-sitter. LLM пишет только тексты описаний.
- Граф: один JSON на исходный файл в `.clewmap/modules/`, только исходящие связи, стабильная сериализация.
- Описания кэшируются по `bodyHash`; без изменения хэша LLM не вызывается.
- Git-хуки не блокируют коммит дольше пары секунд и всегда выходят с кодом 0. Исключение одно, по решению автора от 24.11.2026: явно включённый `hooks.summarize: "pre-commit"`, тогда коммит ждёт описания не дольше `hooks.summarizeTimeout` секунд (`null` — без лимита).
- Hover в расширении никогда не вызывает LLM.
- Всё локально: никакой обязательной телеметрии, никаких своих серверов, ключи только из окружения.
- `spawn` с массивом аргументов, без shell.

## Команды
- `pnpm -r build` — сборка всех пакетов
- `pnpm test` — тесты (Vitest)
- `pnpm --filter @clewmap/vscode dev` — расширение в Extension Development Host
